Order Service — ER Diagram

erDiagram
    orders {
        string order_id PK "UUID, 系统自动生成"
        string customer_name "客户姓名, NOT NULL"
        string phone "联系电话, NOT NULL"
        string service_address "服务地址, NOT NULL"
        enum service_type "CLEANING | REPAIR | INSTALL | OTHER"
        string appointment_time "预约时间 ISO8601"
        int estimated_duration_minutes "预计服务时长(分钟)"
        enum status "CREATED→PENDING→ACCEPT→COMPLETE→PAID"
        string assigned_worker_id "指派的师傅ID, nullable"
        datetime status_updated_at "状态变更时间"
        datetime created_at "创建时间"
        datetime updated_at "更新时间"
    }

Order Status State Machine

stateDiagram-v2
    [*] --> CREATED: Customer/CSR creates order
    CREATED --> PENDING: Order submitted for dispatch
    PENDING --> ACCEPT: Worker accepts order
    ACCEPT --> COMPLETE: Worker finishes service
    COMPLETE --> PAID: Payment completed
    PAID --> [*]
